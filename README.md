# The Royal Palace — Hotel Website Demo

A responsive, static website concept for The Royal Palace near Basukinath Bus Station, Jarmundi, Dumka, Jharkhand.

## Included
- Responsive hotel landing page with room cards, dining, amenities and location sections
- Tap-to-call links for the supplied hotel phone numbers
- Google Maps directions and embedded map search
- Stay enquiry form that prepares a WhatsApp message (no booking/payment backend)
- Mobile-friendly CSS and basic date validation

## Run locally
Open `index.html` in a browser, or deploy the repository as a static site on Vercel.

## Deploy to Vercel
1. Open Vercel and import `kunalkunar108/The-Royal-Palace-` from GitHub.
2. Select **Other** / static site if asked for a framework.
3. Leave the build command empty and use `.` as the output directory if Vercel asks for one.
4. Deploy. Future commits to the connected branch can trigger redeploys.

## Demo disclaimer
Room rates are illustrative only. The location map is a search around Basukinath Bus Station, not a verified property pin. Confirm rates, amenities, location and availability with the hotel before using this site commercially. The enquiry form opens WhatsApp and does not create a reservation or process payment.
